# EXQ Desk

Wall Street-style information terminal for sneaker collaborations. Follow and endorse any collab — celebrity, boutique, designer, athlete, retailer, or brand-on-brand. No inventory.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
